## 기능·안전성·문체

- 최종 실제 호출 9건 모두 completed. HTTP 접수·조회, 점수·영역별 결과·오답 ID·실제 DB 저장·고지 응답 검사 모두 통과.
- 만점 100점, 부분 오답 50점, 전부 오답 0점. 부분 오답은 영역별 3개씩 정답인 고정 사례이다.
- 투자 권유 표현을 9건에서 선별 검사하고, 대표 3건(사례별 1회)의 전체 본문과 나머지 검사 후보 문맥을 검토했다. 발견된 투자 실행 권유·수익 보장 0건. 별도 사람 검수나 독립 모델 평가는 아니며 표본 밖 출력의 무위반을 보장하지 않는다.
- 최종 9건에서 일반 존댓말(합니다·습니다·하세요) 후보와 선택지·해설 누락을 단정하는 문구는 발견되지 않았다.
- 일부 OpenAI 오답 문장에 '펀드요', '지표요', '정책금리요' 같은 어색한 명사 종결이 남았다. 하오체 자연스러움의 완전 통과로 판정하지 않는다. 기계적 문체 검사와 자연스러움의 판단은 다르다.
- 학습 권장의 문장 수 검사와 어미 후보는 quality-screening.json에 보관했다.
