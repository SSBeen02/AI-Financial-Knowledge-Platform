## 현재 상태 요약

Stage 1→2, 2→3, 3→4, 4→5 및 Stage 5 최종 완료는 화면·게임 보상·재진입에서 확인됐다. 다만 Stage별 잔여 개념은 백엔드에서 보조 완료 처리했으므로, 모든 개념의 사이트 질문·퀴즈가 검증된 것은 아니다. Stage 5 최종 상태는 70/70, 2500엽전, 특별편 100%다. 박서현·안유빈의 독립 로컬 회귀는 각각 195개 통과했지만 배포 사이트 동작의 증거로 합산하지 않는다.

후속 재시험은 기존 `김아주` 계정(Stage 5 완료)과 새 `김아주주` 계정(Stage 1)을 사용했다. `김아주주`의 마지막 상태는 **2/30·학습중 0·미학습 28, 20엽전·첫 번째 장 6%**다. IT-04 범위 밖 안내와 IT-02 이전 시도 대화 복원은 재시험에서도 실패했다. 배포 화면에 빌드/커밋 정보가 없어 중간에 수정 버전이 배포됐는지는 확인할 수 없다.

## 결론: 수정해야 할 사항

1. **우선 수정 — IT-04 범위 밖 분류:** 비경제 질문에 별도 `notice`가 생성·표시되도록 검색·분류 기준을 고친다. 학습 시작·퀴즈·진행 상태를 바꾸지 않는 기존 동작도 유지되는지 확인한다.
2. **우선 수정 — IT-02 재학습 이전 대화:** 미통과 뒤 `재학습하기`에서 이전 attempt의 질문·답변을 현재 대화와 구분해 보여준다. `렌트 푸어`와 `워킹푸어` 두 개념에서 재현됐다.
3. **제품 기준 확정 후 수정 — 자유 대화 보존:** 자유 질문·답변과 복습 안내를 새로고침·재로그인 후 유지할지 정한다. 유지가 요구사항이면 저장·조회 경로를 수정한다.
4. **정확성·분류 검토 후 수정:** `ETF`/`상장지수펀드` 별칭, `연금저축` 보험·펀드 비교 답변 및 세액공제 한도 표현, `소득세` 후속의 `이자소득` 범위 안내, 블록체인의 일률적 `다수결` 설명을 확인한다. 사실·제품 기준상 잘못된 항목을 수정한다.
5. **UI 상태 점검:** Stage 4에서 답변 후 입력·완료 버튼이 한동안 비활성화된 현상과 완료 직후 메인 보상·이야기의 이전 값 표시를 점검한다. 단발 `Failed to fetch`의 반복 여부도 관찰한다.
6. **배포 버전 표기:** 화면이나 진단 정보에서 배포 커밋/버전을 확인할 수 있게 해 수정 전후 결과를 구분한다.

## 별도 시행할 시험과 판정 한계

- **IT-8 배포 성능시험:** 첫 글자 시간·응답 완료 시간 등의 목표치와 계측 환경을 정한 뒤 별도 실행한다. 지금까지 첫 글자 시간은 측정되지 않았다.
- **IT-9 외부 사용자 시험:** 실제 다른 참가자가 과제를 수행하는 시험이다. 참가자·과제·판정 기준을 정해 별도 진행한다. 이 재시험의 에이전트 결과로 대신하지 않는다.
- Stage별 미검증 잔여 개념은 백엔드 보조 완료 대상이었다. 합의한 범위는 **Stage마다 4개 상세 UI 검증**이며 모든 개념을 UI에서 시험했다고 보고하지 않는다.
