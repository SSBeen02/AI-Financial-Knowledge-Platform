# 자동 회귀시험 (공통 로컬 실행)

<!-- 목적: Stage 1~5 공통 로컬 백엔드 계약 회귀. 제한: 배포 사이트, 공유 계정, 실 DB·Qdrant·LLM에 접속하지 않으며 UI 통합시험을 대체하지 않는다. -->

이 자동시험은 Figma 웹사이트가 아니라 각 팀원의 저장소 로컬에서 Python 백엔드 테스트로 실행한다. 세 담당자가 같은 커밋에서 같은 명령을 사용한다.

저장소 루트의 PowerShell에서 실행한다.

```powershell
.\scripts\run_automated_regression.ps1
```

테스트는 mock/로컬 임시 DB를 사용하고 운영 URL, 시험계정, 실 API 키를 설정하지 않는다.

포함 범위:

- RAG `stages.json`의 Stage 1~5 전체 개념 목록·순서·중복, 추천·상태/단계 경계 동작
- 학습 관리 DB 계약 및 퀴즈 생성 완료·실패 연동
- 퀴즈 어댑터의 멱등 생성·결과 전달 계약과 대화 상태
- Stage 5 고정 문제 뱅크 전체 개념의 3문항 및 AI 생성기 비호출 계약
- 공통 인증, 사전테스트 완료·복원, 게임 이벤트·보상·멱등성, 학습노트 계약

각 묶음의 종료 코드와 통과 개수, 사용한 커밋을 실행 ID `SYS-IT-2026-01` 기록에 첨부한다. 한 묶음이라도 실패하면 회귀시험은 실패다. 브라우저 화면, Figma 배포, 실제 Qdrant/LLM 응답, 첫 글자 시간, 외부 사용자 과제는 검증하지 않는다. 사이트 시험 프롬프트는 담당자별 `통합테스트_에이전트_선빈.md`, `통합테스트_에이전트_서현.md`, `통합테스트_에이전트_유빈.md`를 사용한다.
