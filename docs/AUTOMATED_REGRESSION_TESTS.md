# 자동 회귀시험 (공통 로컬 실행)

<!-- 목적: Stage 1~5 공통 로컬 백엔드 계약 회귀. 제한: 배포 사이트, 공유 계정, 실 DB·Qdrant·LLM에 접속하지 않으며 UI 통합시험을 대체하지 않는다. -->

이 자동시험은 Figma 웹사이트가 아니라 저장소 로컬의 Python 백엔드 계약을 검사한다. 배포 사이트에서 진행하는 `SYS-IT-2026-01` 통합시험과 판정을 분리한다.

## 현재 실행 ID의 회귀 결과

- 사용자가 로컬 회귀 **135+6+54=195개 통과**를 별도로 확인했다. 이는 사용자 확인 결과이며, 후속 통합시험 에이전트가 재실행하거나 직접 검증한 결과가 아니다.
- 박서현(Stage 3·4)과 안유빈(Stage 5)은 같은 실행 ID의 사이트 시험을 이어간다. **이번 인계에서는 로컬 회귀를 재실행하지 않는다.** 코드 변경이나 별도 재검증 요청이 생기면 그때 실행 커밋, 각 묶음의 출력·종료 코드·통과 수를 새 결과로 기록한다.
- 로컬 회귀 195개를 사이트의 질문·학습·퀴즈, 실제 검색·스트리밍, 게임 보상 또는 Stage 전환의 통과 증거로 합산하지 않는다.

## 별도 재검증이 필요할 때의 실행 방법

저장소 루트의 PowerShell에서 실행한다.

```powershell
.\scripts\run_automated_regression.ps1
```

테스트는 mock/로컬 임시 DB를 사용하고 운영 URL, 시험계정, 실 API 키를 설정하지 않는다.

포함 범위:

- RAG `stages.json`의 Stage 1~5 전체 개념 목록·순서·중복, 추천·상태/단계 경계 동작
- 학습 관리 DB 계약 및 퀴즈 생성 완료·실패 연동
- 퀴즈 어댑터의 멱등 생성·결과 전달 계약과 대화 상태
- Stage 5 고정 문제 뱅크 전체 개념의 3문항 및 AI 생성기 비호출 계약
- 공통 인증, 사전테스트 완료·복원, 게임 이벤트·보상·멱등성, 학습노트 계약

재검증을 실행한 경우에만 각 묶음의 종료 코드와 통과 개수, 사용한 커밋을 실행 ID `SYS-IT-2026-01` 기록에 첨부한다. 한 묶음이라도 실패하면 그 실행의 회귀시험은 실패다. 브라우저 화면, Figma 배포, 실제 Qdrant/LLM 응답, 첫 글자 시간, 외부 사용자 과제는 이 스크립트로 검증하지 않는다. 사이트 시험의 순서·판정·토큰 부족 시 재개 절차는 `docs/통합테스트_공통_실행기준.md`를 따른다.
