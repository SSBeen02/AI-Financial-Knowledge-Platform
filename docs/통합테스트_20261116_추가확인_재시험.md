| 확인 항목 | 조작·관찰 | 판정 |

| IT-04 범위 밖 안내 | Stage 5 자유 질문 `고양이는 왜 꼬리를 흔드나요?` 전송. 답변은 고양이 행동과 경제 용어 `Wag the Dog`, `꼬리 위험`을 연결했다. **별도 범위 밖 안내는 표시되지 않았다.** 해당 질문의 학습 시작 추천이나 퀴즈는 없었고, 학습 완료 버튼은 비활성화 상태였다. | **실패 재현**. 이전 박서현·안유빈 관찰과 일치한다. 이번에는 API 응답 필드를 직접 조회하지 않았다. |

- IT-8 배포 성능: 별도 시험 기준과 계측 환경이 기록에 없어 이번 기능 재시험에서 통과 판정하지 않았다.
- IT-9 외부 사용자 시험: 실제 외부 참가자가 수행할 항목이므로 여기서 실행하지 않았다.

## 2. 새 시험 계정

사용자가 직접 로그인하고 사전테스트·초기 설정을 완료했다. 사이트 표시명은 **`김아주주`**다. 시작 상태는 Stage 1 **0/30·학습중 0·미학습 30**, 꽃거지·0엽전·첫 번째 장 0%였다. 기존 `김아주` 계정과 구분한다.

| 확인 항목 | 조작·관찰 | 판정 |
|---|---|---|
| IT-04 미통과 다른 Stage 정규 개념 | Stage 1에서 `상장지수펀드에 대해 알려줘` 자유 질문. 답변과 출처 뒤, 이 개념은 현재 Stage 1이 아닌 **금융과 투자**에서 배우므로 이번 Stage의 성장·퀴즈에 반영되지 않는다는 안내가 표시됐다. 학습 시작 추천·완료 버튼은 활성화되지 않았고 질문 뒤 Stage 1 0/30·학습중 0·미학습 30을 확인했다. | **통과**. 미통과 다른 Stage의 정규 개념 경로를 새 계정에서 직접 확인했다. |
| IT-04 약어 인식 검토 후보 | 같은 뜻의 `ETF에 대해 알려줘`는 관련 답변·출처 뒤 `학당의 정규 과정에는 없지만`이라는 안내가 나왔다. 정규 개념 `상장지수펀드`의 약어인데도 다른 Stage 정규 개념 안내와 달랐다. | **분류/별칭 검토 후보**. 학습 상태는 변하지 않았다. |
| IT-02 미통과→재학습 이전 대화 | Stage 1 추천 `렌트 푸어` 선택, 첫 질문 `렌트 푸어에 대해 알려줘`, 후속 `렌트 푸어와 하우스 푸어는 어떤 차이가 있나요?`에 답변·출처를 확인했다. 학습중 1·미학습 29. 완료 후 퀴즈 attempt 1에 **X/O/B**를 제출해 **0/3, 재학습 필요**가 표시됐다(정답 O/X/C). `재학습하기` 클릭 직후 학습중 1은 유지됐지만 대화 영역에는 **첫 시도의 두 질문·답변이 보이지 않았다**. | **결함 재현**. 김선빈의 이전 관찰과 일치한다. |
| IT-05 재학습 중 새로고침 | 재학습에서 `렌트 푸어가 되지 않으려면 주거비를 어떻게 관리해야 하나요?`를 보내 관련 답변·출처를 확인했다. 새로고침 → 메인 → 학습 재진입 후 Stage 1 학습중 1·미학습 29 및 **재학습 질문·답변이 복원**됐다. 첫 시도의 두 질문·답변은 여전히 보이지 않았다. | **현재 attempt 대화 새로고침 복원 통과**, 이전 attempt 대화 복원 실패 유지. 재로그인 검증은 아래에서 별도 진행한다. |

### 재로그인 후 결과와 최종 상태

- 사용자가 같은 `김아주주` 계정으로 직접 재로그인했다. 메인 꽃거지·0엽전·첫 번째 장 0%, 학습 Stage 1 **통과 0/30·학습중 1·미학습 29**로 로그아웃 전과 일치했다.
- 학습 화면에는 현재 재학습 질문 `렌트 푸어가 되지 않으려면 주거비를 어떻게 관리해야 하나요?`와 답변·출처가 다시 표시됐다. 완료 버튼도 활성화됐다. **현재 attempt의 학습중 모드·대화 재로그인 복원은 통과**했다. 첫 attempt의 두 질문·답변은 재로그인 뒤에도 표시되지 않아 IT-02 결함은 열린 상태다.
- `학습 완료 · 퀴즈로`를 눌러 생성된 두 번째 3문항을 확인했다. Q1 주거비가 소득 대부분을 차지하는 사람 → **O**, Q2 집값 하락으로 소득이 줄어든 사람 → **X**, Q3 월세 부담 시 저렴한 주거지 이사 고려 → **B**를 제출했다. 세 문항 모두 `정답입니다`, **attempt 2: 3/3 통과**를 확인했다.
- 다음 학습 화면에서 Stage 1 **통과 1/30·학습중 0·미학습 29·진행률 3%**, 추천 목록에서 `렌트 푸어` 제외를 확인했다. 학습노트는 `렌트 푸어` **총 2회 풀이·6개 기록**, 2회차 통과였다. 메인 진입 직후 0엽전·이야기 0%가 잠시 보인 후 **10엽전·첫 번째 장 3%**로 갱신됐다.
- 마지막 확인 화면: `김아주주` 메인, Stage 1, 꽃거지·**10엽전**·첫 번째 장 **3%**. 새 시험 계정의 진행은 유지한다.

## 판정 정리 및 남은 범위

| 항목 | 이번 재시험 판정 |
|---|---|
| IT-02 | 미통과→재학습→attempt 2 통과와 보상은 확인. **이전 attempt 대화 미표시 결함 재현**으로 전체 통과는 아님. |
| IT-04 | 범위 밖 안내 **실패 재현**. 미통과 다른 Stage 정규 개념과 기통과 이전 Stage 개념 안내는 각각 **통과**. `ETF` 약어의 정규 개념 매핑은 검토 후보. |
| IT-05 | 현재 학습중 attempt의 대화·모드는 새로고침과 사용자 직접 재로그인 뒤 **복원 통과**. 자유 대화는 `김아주` 계정에서 새로고침 후 미표시를 확인했지만, 이번 실행에서 자유 대화 재로그인까지 반복하지 않았다. |
| IT-07 | 이번 새 계정에서는 완료 버튼 연속 클릭을 반복하지 않았다. 기존 김선빈의 서버 중복 방지 결과와 안유빈의 Stage 5 화면 결과를 이번 직접 시험 결과로 합산하지 않는다. |
| IT-8 | 성능 측정 기준·계측 환경이 정해지지 않아 별도 미실행. 첫 글자 시간 통과 판정 없음. |
| IT-9 | 실제 외부 사용자가 수행할 별도 시험. 이 실행에서는 제외. |

배포 화면에서 빌드/커밋 정보는 보이지 않았다. 위 재현 결과는 테스트 시점의 배포 사이트에 한정된다.

## 3. 같은 배포 사이트 재시험 — `김아주주`

- 2026-11-16 KST, 같은 사이트의 새 브라우저 탭에서 기존 로그인 세션을 확인했다. 시작 상태는 `김아주주`, Stage 1 **1/30·학습중 0·미학습 29**, 10엽전·첫 번째 장 3%였다. 배포 빌드 정보는 여전히 화면에서 확인되지 않았다. 배포가 변경됐는지는 확인할 수 없다.

| 항목 | 실제 조작과 관찰 | 판정 |
|---|---|---|
| IT-04 범위 밖 안내 | 자유 질문 `고양이는 왜 꼬리를 흔드나요?`를 다시 전송했다. 답변은 고양이 행동을 설명하고 `Wag the Dog`, `꼬리 위험`을 언급했지만 **별도 경제 학습 범위 밖 안내는 없었다**. 학습 시작·완료 버튼은 활성화되지 않았고 Stage 1 상태는 1/30·0·29로 유지됐다. | **실패 재현**. 응답 본문이 비경제 질문임을 일부 인식한 듯 보여도 별도 안내 기준은 충족하지 못했다. |
| 자유 대화 새로고침 복원 | 위 질문·답변 표시 후 새로고침 → 메인 → 학습 재진입. 질문·답변은 보이지 않고 초기 대화 안내만 표시됐다. Stage 1 1/30·0·29는 유지됐다. | **미표시 재현**. 자유 대화 보존이 제품 요구사항인지 확인하고, 요구사항이면 수정 후 재시험한다. |
| IT-02 이전 attempt 대화 | 미학습 `워킹푸어`를 추천에서 선택해 `워킹푸어에 대해 알려줘`, 후속 `워킹푸어와 실업자는 어떻게 다른가요?`의 답변·출처를 확인했다. 첫 퀴즈 실제 3문항에 **X/O/D**를 제출해 **0/3**(정답 O/X/B)이 표시됐다. `재학습하기` 직후 Stage 1 **통과 1·학습중 1·미학습 28**은 유지됐지만 첫 시도의 두 질문·답변은 대화 영역에서 **보이지 않았다**. | **결함 재현**. `렌트 푸어`에 이어 두 번째 개념에서 동일한 현상을 확인했다. |
| IT-02 재학습 완료 | 새 질문 `워킹푸어는 왜 일해도 가난에서 벗어나기 어렵나요?`에 답변·출처를 받은 뒤 두 번째 퀴즈에 **O/X/C**를 제출했다. 세 문항 모두 정답, **3/3 통과**. 학습 화면 Stage 1 **2/30·학습중 0·미학습 28·진행률 6%**. 메인은 이전 10엽전·3%를 잠시 표시한 뒤 **20엽전·첫 번째 장 6%**로 갱신됐다. | 미통과→재학습→통과·보상 흐름은 정상. **이전 대화 미표시 결함은 유지**. |

이번 재시험에서 IT-04와 IT-02의 해결 증거는 얻지 못했다. 별도 수정·재배포 여부를 확인할 빌드 정보가 없어 같은 배포에 대한 재현 결과로 기록한다. IT-8 성능시험과 IT-9 실제 외부 사용자 시험은 이 기능 재시험에 포함하지 않았다.
