## 방식 및 범위

실제 SQLAlchemy/asyncpg 연결과 list_concepts·submit_review 함수를 사용했다. 저장 검증은 외부 트랜잭션과 세션 savepoint를 사용하여 함수 내부 commit을 실행하되 최종적으로 외부 트랜잭션을 롤백했다. 별도 연결에서 검증용 멱등 키의 기록이 0건임을 확인했다.

이번 접근 차단 검사는 서비스의 사용자 소유권 검증에 대한 것이다. 실제 로그인 토큰·프론트엔드 HTTP 통합과 Supabase anon/authenticated 역할의 RLS 정책 검증은 포함하지 않았다. 현재 8011 quiz_preview 화면은 임시 SQLite를 사용하므로 위 실제 DB 함수 검증과 구분한다.
